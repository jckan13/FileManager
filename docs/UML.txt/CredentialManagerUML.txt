Method Summary

CredentialManager()
- Uses the real credential file location: auth/credentials.txt

CredentialManager(File credentialFile)
- Allows tests to use a fake credential file, such as testAuth/loginTest.txt

credentialsExist()
- Returns true if the credential file exists and is a regular file

isValidUsername(String username)
- Returns true only if the username contains lowercase letters a-z

isValidPassword(String password)
- Returns true only if the password is at least 5 characters long

createCredentials(String username, String password)
- Validates the username and password
- Creates the parent folder if needed
- Writes the username and password to the credential file

login(String username, String password)
- Reads the stored username and password from the credential file
- Returns true if both match the given username and password

changePassword(String username, String currentPassword, String newPassword, String confirmPassword)
- Verifies the current username and password
- Checks that the new password and confirmation match
- Checks that the new password is valid
- Overwrites the credential file with the updated password
