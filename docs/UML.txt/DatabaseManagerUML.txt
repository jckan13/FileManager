DatabaseManager
-----------------------------------
The central database access class for the TopSecret system.
It implements MissionRepository, FacilityRepository, AgentRepository, and AuditLogRepository,
providing real SQLite-backed data for all entity types.

It manages a single shared connection to the SQLite database and initializes
five tables on startup: facilities, agents, missions, mission_agents, and audit_log.
Tables are seeded from TSV files if empty.

Database integrity is enforced on all delete operations:
- deleteFacility is blocked if any agents or missions still reference it.
- deleteAgent is blocked if the agent is staffed on any active missions.
- deleteMission cleans up mission_agents rows before deleting the mission.
- removeAgentFromMission is blocked if only one agent remains on the mission.
