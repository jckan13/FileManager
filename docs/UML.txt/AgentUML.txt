Agent

Represents a secret agent in the system.
Stores the agent's name, date of birth, date of death, notes, and the facility they are assigned to.
Agents are assigned to one and only one facility.
Agents can be staffed on one or more missions via the mission_agents junction table.
Used by DatabaseManager to map rows from the agents table into Java objects.
