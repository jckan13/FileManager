AgentRepository

An interface that defines how the rest of the system accesses agent data.
It decouples ProgramControl and the UI from the database implementation,
meaning they do not need to know anything about SQLite.

DatabaseManager implements this interface to provide real data from the SQLite database.
FakeAgentRepository implements this interface in tests to provide controlled test data.
